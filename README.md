# Liked Music Exporter

Chrome extension that turns your Liked Music into a public playlist, copies the link and opens it.

> [!IMPORTANT]
> **Your Google account must have a YouTube channel**, otherwise this extension will not work (you will get a "no YouTube channel" error).
> Create one first: youtube.com → profile picture → **Create a channel**.

## Install

### Chrome store installation

Just use this [link](https://chromewebstore.google.com/detail/liked-music-exporter/nncpegdpelgckepjoihjdmobmgbikknn) to install the extension, you are welcome!

### Or you can install dev

1. On this GitHub page click **Code → Download ZIP**.
2. Unzip it.
3. In Chrome open `chrome://extensions` and enable **Developer mode** (top right).
4. Click **Load unpacked** and select the `extension` folder from the unzipped files.

![Guide](assets/guide.gif)

## Use

1. Open [music.youtube.com](https://music.youtube.com) and log in.
2. Click the extension icon, then **Create playlist**.
